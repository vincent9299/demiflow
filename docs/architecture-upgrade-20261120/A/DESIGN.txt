MERGE_TREE/受测源码/无 unstaged 变化核对证明；工具只分析其固定 Git 对象，不能给实时树背书。

4.7 A2 有界资源与清理（仅本工具）
最多两个固定源快照顺序分析；Git 只读 ls-tree/cat-file，不 git checkout/reset/write-tree、不解压业务目录。
在读取 blob 前核对 Git 对象类型/模式及声明字节数；.py symlink/special entry 显式失败，不能追到树外。
每快照：至多 4096 个 Python 模块、单 blob 2 MiB、源码总 64 MiB、路径 1024 字节；
树元数据至多 20000 项/4 MiB、边至多 50000；达到边界立即 failed，不截断成完整报告。
每次只解析一个 blob，AST 用后释放；保留有界模块/边表。SCC 实现避免不受控 Python 递归。
总墙钟 90 秒，软件阶段期限 60 秒；最多一个分析子进程及一个串行 Git reader，不扫描业务仓或安装依赖。
第三方/操作系统分配不冒充硬内存保证；分析子进程设置 512 MiB 地址空间和 60 秒 CPU 后备限制，
主动输入/边预算仍是主要限制，记录实际预算/elapsed 与限制支持情况。
每主报告最多 8 MiB，编码写入到本任务临时文件时计量；stderr/错误摘要最多 64 KiB。
全新仓外 output-dir 禁止覆盖旧版本；先写有界临时报告，再发布两份结果及 receipt，任何缺失明确失败。
异常/超时/取消关闭 pipe、回收本工具子进程及私有临时文件；已写失败回执和首次错误保留。
只清本任务临时目录，不终止他人进程或删除历史报告。报告未完成时不留下看似成功的空主报告。
