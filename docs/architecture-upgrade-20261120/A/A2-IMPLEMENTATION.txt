改前→改后与职责

改前只有仓库外可复用分析脚本，读取工作目录，旧 SCC 递归且假定锚点在环内，语法错误会略过，没有固定双对象报告/失效回执。
改后新增一个有限 stdlib/Git 只读工具：读取完整 commit/tree SHA 的模块清单及 blob，逐份 AST，迭代 SCC，生成两份主报告和外围 receipt。
复用旧 graph 导入解析/类别与 facts 的种子/闭包/SCC 定义，原件路径和精确 SHA 写进工具及 method，不在运行时依赖共享脚本，也不复制旧展示/模拟 cut。
公开门面、执行器、业务对象、历史账本或资源 owner 不变；工具没有插件/注册中心/五层规则，也不执行被分析模块。

SCC 报告完整列两个版本组件成员/路径、missing/acyclic/cyclic 锚点，区别新建/原有成员入环、保留退环/删除及组件交集的 merge/split。
声明报告列实际/缺失/新增种子、top/guarded 闭包、种子跨旧口径包的 top 候选和闭包外 lazy 到底座 SCC 内外两组；每名和位置保留。
依赖 key=(src,dst,names,kind) 聚合，行号变化只记 relocated。typing、literal dynamic、符号字符串和 computed unknowns 单列，不混入静态 SCC。
无静态边不证明运行无依赖；函数 lazy 包含 defaults/decorators/annotations，直接 TYPE_CHECKING 才识别，别名、反射、可达性、动态调用来源不保证。
“向上”仅是明示旧候选定义，不是已批准分层规范或违规判决；SCC/导入数增加也完成报告，不触发阈值失败。

输入/输出/错误与可选 gate

base 必须 full commit SHA，candidate 可 full commit/tree，tree commit_sha=null；Git replace/继承 GIT_* 路由禁用，只用 cat-file/ls-tree。
不 checkout/write-tree/写Git引用/INDEX，不把未提交工作区混入；实际测试树与 staged tree 的对应仍由管理者证明。
输出必须仓外全新目录，已有证据拒绝覆盖。两份有界临时主报告先写完再发布；异常清本次 partial，能写时留下 failed receipt，不能写时如实缺失/非零，不伪造空成功。
主报告同输入/工具逐字节确定；时刻/耗时/绝对输出路径只在外围 receipt。路径、对象类型、模块/blob/总源、metadata、观察行、输出、deadline 都有主动上限。
CLI 是一个独立分析进程（512MiB AS、60s CPU 后备、90s wall timer），软件阶段60s，最多一个串行 Git child；函数 API 不改当前 pytest 的 OS 限制。
Git header 大小先准入再读body；.py symlink/special mode/语法错误明确失败，不静默跳过。资源限值、实际 OS 后备可用性和耗时如实记录，不称宿主 RSS 保证。

可选 gate 三参数只在原 gate 结果之后运行工具。默认 diagnostics.status=not_requested 明示未生成；少参数/工具/输入/预算/写入/超时/损坏结果为 failed。
complete 需实际两文件、输入匹配、字节/摘要和 receipt 一致；工具报告异常不读写 result.ok，最终 CLI 退出仍由真实 guard 决定。
真实 guard fail+complete 仍失败，guard pass+failed 仍保留成功和报告失败两个事实。JSON 总回执写不出仍是缺证据，不能声称交付。
A1 的 GUARDS/FROZEN、完整冷导入、fixture、原元测试 AST 和 skip 拒绝不变；没有 allow-skip、全仓政策改变或报告失败阻断 A1/P12。
具体命令、字段、限制和恢复见 DIAGNOSTICS-USAGE.txt；不改现行发版规范，不替管理者执行合流/发布。
