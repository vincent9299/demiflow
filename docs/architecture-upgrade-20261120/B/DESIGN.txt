4. 索引接口、写者与失败窗口

不新增磁盘类型。内部 IndexEntry 用普通 dict，字段严格为 kind/identity/created_at/digest/active；Missing 采用 None，且仅所有者确认源不存在才可给出。index 负责类型、finite 非负时间、布尔 active、身份/摘要格式、与 marker 一致性；所有者负责源真实性。

index.begin(root,kind,identity)->现有 marker；index.publish(root,marker,entry_or_missing)->None 或 <=1024 字错误。
run_index_entry(root,run_id)、workspace.report_index_entry(root,digest)->entry|None。
owner.publish_*_index(root,marker)->None|有界错误，并在失败时一次有界诊断。

owner 必须在同一个 try/except Exception 中先求摘要、再调用 publish；不能把求值写到 index 的异常边界之外。index.publish 返回的错误也触发同一诊断。诊断含 kind/identity、错误和同步入口，本身失败不能改变源响应。BaseException 不吞，中断保留 marker 作为显式恢复证据；不将诊断写入带 digest 的 manifest/report 或新增成功响应字段。

run owner 沿既有 directory + observe_storage.exists + _load(detail='identity')；created/digest 来自 manifest，active 来自原 ACTIVE。report owner 沿 load_report、mtime。权限失败、损坏、RunReadError、超时/预算超限均不是 Missing。Missing 完成本 marker 但不删除旧条目；rebuild 遇枚举到的源 Missing 必须失败，不能宣称完整。

publish 保持先事务提交，再核对精确 generation 后清 marker；旧 generation 不能写/删新 marker。相同摘要重试不增加成员，保留 created 排序；revision 仍是提示而非权限/事实版本。索引更新失败不回滚已发布源，不覆盖原业务异常。
