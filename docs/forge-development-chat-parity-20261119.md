# 开发对话整页移植（2026-11-19）

用户要求是复用 DeepSeek Harness Web 的完整对话页面。上一版只替换部分过程行和输入控件，仍把消息送入通用文件阅读器，暴露原文分页、UTF-16 字符位置和多余留白；本次以用户提供的三张截图作为交互与布局目标。

## 页面行为

- Chat / Trajectory 与 Standard / Compact / Detailed 显示模式；普通用户消息采用右侧气泡、时间与复制按钮。
- 以轮次组织 Completed / Working、Ran commands / Used tools 与 Think / Bash / 具体工具的一行摘要；默认展开最近轮的过程组，详细正文按需展开。用户手动折叠不被新消息覆盖。
- 最终回复直接呈现安全 Markdown。过程长文不会占满页面，原文只在详细模式或展开操作中按需查看。读取完整原文仍绑定 session / turn / epoch / sequence，不改历史。
- 白色输入卡片包含可选引用、文本附件、真实权限、已配置模型和 effort、发送/停止；保留草稿、中文 IME、发送幂等、断线续看与滚动位置。
- 底栏展示持久化公开事件计算的轮数、步数、速度、token、缓存命中与上下文占用。没有记录的值不填 0，不把当前可见窗口冒充全会话；部分历史统计在实际读数的提示中说明。

## 模块契约

`development-chat.js/css` 拥有消息投影与轮次展开，保留 sourceRef 原文引用；不发模型请求。`development-composer.js/css` 拥有菜单、附件、模型与统计展示；主接线继续拥有草稿、IME、发送与取消。`reading.js` 新增无文件工具栏的 createMarkdownView，使用既有安全解析器、一个独立有界 worker 队列和明确销毁生命周期。主接线仅调度这些组件及工作台原有 API。

`dev-stats` 在既有工作区授权下增量折叠已持久化事件；每次最多 2048 行 / 2 MiB，缓存最多 16 个会话。固定 DeepSeek 插件导出数值白名单，不导出原始模型帧或私有历史；同一步的 usage 替换、明确 retry 后累加，压缩事件不计入开发轮统计。

## 复用与边界

基于本机 @deepseek-ai/dsh 0.2.1-rc.2 的 MIT 组件结构、样式、SVG 与行为适配工作台协议，保留许可。没有嵌入独立 DSH 服务，也没有替换 Forge 控制器或取消门禁。原生 Full access 入口映射为当前真实授权说明；模型只能使用服务已配置的接入，旧会话保持绑定。加号支持可选文件/目录引用及有限大小的 UTF-8 文本附件，不宣称已有图片上传能力。

- 11 个 HTTP、压缩与补充问题用例通过。
