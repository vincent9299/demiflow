## 多会话契约

- `new_conversation=true` 才显式创建独立可写会话；省略时保持旧主会话复用语义。新建草稿不预先创建后台会话，首次发送才创建。
- 显式成员与会话原子持久化；旧主会话保持可写，其他旧归档不批量升级。项目、物理根、策略和 provider 身份继续校验。
- `dev-sessions` 返回有界的会话页、可写性、最小运行状态、当前项目是否有写入及可公开的活动会话 ID。`dev-project-turns` 可按会话筛选，省略筛选保留旧聚合契约。
- 同一物理根及重叠目录的开发写入继续互斥。切换会话不取消后台运行；其他会话可查看并编辑自己的草稿，活动写入结束后可发送。
- 草稿按项目与会话分别存储；刷新和前进后退保留选择。旧界面模式/详情/轨迹仍可从会话菜单进入，不增加第二层固定页头。

## 文档目录与资源边界

文档接口只读当前项目：目录按需展开，每页最多 50 条；每次扫描最多 4096 项、名称总量 512 KiB，展开节点最多 300 个；单文件上限 1 MiB。隐藏目录、环境目录、Lance 表目录及符号链接不进入目录。拒绝越界与非 Markdown 文件，复用现有有界文件读取和阅读器。URL 保存文件路径，支持切换、刷新与前进后退；不新增文档编辑。

运行目录复用当前分页结果，未扩读全部历史；会话目录每页最多 20 项。旧表数据、Notebook 输出、开发历史及权威验收记录不因导航更新而重写。
