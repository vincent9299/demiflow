# 用户最终看到什么

以下是本批的目标验收结果，当前不是已实现声明。

## 产品

仍在同一个工作台里选项目、流程、参数和运行。执行后看到的图来自当次真实封存计划；点节点能回到当时代码和参数，能看输入/输出端口、所在CPU/GPU/远程API资源组、通道为什么增量或等待完整输入、真实状态和指标。融合节点没有独立观测就明说，不再用“契约通过”给静态推测图背书。

同一业务里可以清洗数据、调用异步模型、join/union、排序/聚合并持久化，不因为其中一项只在Local或Ray可用而拆成两条业务。选择Local/Ray改变运行宿主；不要求你在业务中插入materialize来绕过后端能力缺口。

运行失败能明确看到哪里失败、哪些结果已确认、哪些付费效果未知。能恢复的从原cut与固定程序/来源继续；不能自动恢复的在提交前和恢复入口解释原因。停止后能看到退出与资源回收结果，不把按钮点击当停止成功。历史run仍显示当时的图和数据，不受当前编辑污染。

Notebook/SQL、Case比较/标注、开发对话和数据浏览保留，做回归验收；本次不重做这些既有产品领域。产品原root的所有旧未完成项仍要独立记账，不能用引擎完成替代它们。

## Dataset API

保留现有from/read、普通map/filter/flat_map、异步和批算子、模型/工具、关系运算、排序/重分区/随机、统计、物化、写出及迭代接口的既有业务语义。完整98个公开入口处置见API-MATRIX，额外DataAPI/executor内部装配也有逐函数任务。

示意组合仍是普通Dataset调用：来源→CPU map→map_prompt_async/map_embeddings→join/union→sort/aggregate→write_lance。具体参数沿现有签名，模型配置仍唯一，不新增要求业务知道资源协议、journal或控制token的配置。where/limit等已有语义保持；不在业务函数里新造子Dataset绕执行。

引擎自动选择逐条交接、持久增量或完整范围封存，自动按资源与语义拆组，保证预取和展开有界。显式materialize仍用于用户需要复用固定结果时；它不是切换后端的补丁。

可说明的边界：需要全局排序的无限来源必须有有限范围；不可恢复的外部对象不能宣称checkpoint；未知效果不自动重试；原子队列ACK只在原生合法结算边界；旧Ray Data内部调参、私有journal写恢复冲突会给具体迁移说明。目标是可用且诚实，不能为了100%口号放宽数据安全或静默变语义。
