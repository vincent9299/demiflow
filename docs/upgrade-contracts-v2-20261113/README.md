## 怎么分发

0. 直接转发模板见 [派工模板](DISPATCH.md)。
1. 阅读 [用户可见结果](USER-EXPERIENCE.md)、[共享契约](CONTRACTS.md)。
2. 从 [函数任务总表](FUNCTION-TASKS.md) 选择一个叶任务，把对应 `tasks/<ID>.md` 和本目录一起交给 agent。
3. 一个叶任务只修改一个指定函数/方法/数据类声明；不得顺手实现其他叶任务。文件装配负责人由 [文件归属表](FILE-OWNERSHIP.md) 唯一确定。
4. 每个 agent 使用自己的隔离工作树。多个函数位于同一文件时，各自提交针对共同基线的窄补丁，由该文件负责人合并；禁止多人写同一 checkout。
5. 实现、单函数验证、模块组合验证、全局验收分开记录。不能用接口替身通过冒充真实引擎通过。

**每个函数可以独立编码和做契约测试；完整运行必须在合流后验证。** 不要求消费者等待生产者实现才开始；固定的数据定义、样例和错误语义在本包中。消费者不得在生产代码加入假实现、ImportError 回退或另一份计划解释器。
