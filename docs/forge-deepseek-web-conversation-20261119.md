## 复用与用户行为

- 按本机已固定的 DeepSeek Harness `0.2.1-rc.2`、MIT 许可移植 `InputBar` 的布局、发送/停止 SVG、焦点及 IME 行为，`ModelSelect` 的菜单/键盘交互，以及 `ReasoningRow` 的流式一行摘要算法。源码保留版权声明；来源与文件哈希位于共享评审证据。
- 正文收到真实增量即显示；公开过程默认折叠，运行中显示一行摘要，结束后保留紧凑标题。用户展开后，后续增量不会把它自动收起。工具详情继续可展开，原文入口改为轻量图标。
- Enter 发送，Shift+Enter 换行；中文输入法选字不触发发送。运行时同一位置切换为停止按钮，Esc 可停止。模型选择支持键盘、外部点击收起和窄屏显示。仍遵循已有会话的 provider 绑定、发送幂等和只读状态。
- 完成正文替换同一块的流式前缀；原文只读取对应的最终完成范围，避免重复拼接。中断或失败尝试已收到的公开文本保留并标记“未完成”；刷新可从已保存的事件恢复。

## 实际流式链路

官方 ACP 适配器原本只在提交 assistant message 后公开整块文本。本批通过固定插件监听官方 Web 同样使用的 `agent/assistant-stream` 公开事件，向既有 stdio/控制器链路投影文本增量与完成事件。首段立即送出，后续 token 按 150 ms 或 16 KiB 合并；不是把完成文本拆开做动画。

插件在 ACP 启动前就绪，只绑定当前 prompt 的精确根 Agent/Session，忽略辅助代理；仅传递公开 text/reasoning，不传递 replayState、原始模型帧或认证信息。每块使用 submission/attempt/block 身份，完成时根据已提交事件校正正文，并依据 messageId 抑制随后 ACP 的重复正文。工具、用量、原生模型循环和 Forge 控制器继续使用现有路径。维护、独立 Review 和模型代理进程不注入此插件。

资源仍有界：插件单块 128 KiB、单尝试 1 MiB、64 个公开块、128 次尝试、总输出 16 MiB；超限明确终止。通用 stdio reader 在 128 个事件或现有字节队列预算不足时暂停读取，保留最多 `frame_bytes + 1` 的原始缓冲，消费后继续，不抬高原帧/总量上限。前端沿用原有卡片和预览预算，较长内容可分页查看。
