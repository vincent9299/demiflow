# 项目内新增流程与算子：试用修复

真人要求是“在项目下，建立管道流程、或者算子”。用户直接在项目对话中描述需求；开发、提问、回答、登记和验证沿用同一项目及对话。内部基线和验收记录由平台管理。

## 本次修复

- 当前请求与首次历史目标分别进入开发及审阅上下文，项目开发不被首次示例修改永久限定。
- 业务问题进入 `needs_input`，等待真实回答期间不运行验证或审阅；普通后续消息及 CLI 原生问答均能继续。
- 新流程代码与参数写入原有授权目录后，CLI 通过窄工具请求登记。平台在执行进程排空后追加 Forge 声明和工作台入口，刷新上下文并继续验证；不让模型改规范、控制文件、验证命令或运行权限。
- 新算子复用已声明算子目录的静态发现。项目根目录工作台依据显式流程引用选择唯一业务 owner，不猜目录、多 owner 冲突不混合。
- 升级保留原目标、基线、问题、历史接受和原会话。采用精确组件修订，旧版本证据不冒充新版本通过。

实现契约见 [项目开发契约](forge-project-development-contract-20261119.md)。代码在 `gpt_project_development_20261119` 隔离修复，通过后合回指定 `gpt_prompt_replay_20261118` / `fix/prompt-replay-delivery-20261118`；主仓没有产品修改。

## 实测范围与证据

隔离合成项目通过真实浏览器和现有 DeepSeek CLI 完成：先询问质量分阈值 → 同对话回答 0.85 → 新建 `quality` flow、参数和 `quality_pass` 算子 → 受控登记 → 固定检查/测试 → 独立无工具审阅 → `accepted/enforced`。浏览器中能选中新流程，显示读取、筛选、写出三节点，算子页显示 `quality_pass`；原两个流程保留，输出未运行。该数据只有合成 score，不能称为真实图片质量检测。

两次审阅在原 16,384 token 额度下截断并保留 `review_unavailable`。简洁审阅提示单独未解决；调整为有限的 32,768 tokens 后，在同会话后续请求中完整通过。仍保持 low、180 秒、每原请求最多两次 Review、64 KiB 最终结论及完整七项校验；没有重写失败历史、拼接半份结论或自评签发接受。

相关验证包括领域 97 项、控制器 20 项、独立登记边界 26 项、项目发现/算子目录 35 项、审阅 29 项，以及 wheel 完整性和安装验证。部分组重叠，不相加为唯一用例总数。负例覆盖越界、取消、过期、旧 epoch、双声明半写、提交后数据库回滚、陌生字节、并发编辑、第 65 条流程拒绝以及原基线/收据保持。

记录在工作区 `_demiflow/shared-review/forge-project-development-20261119/`：`real-first-failure.json`、`real-second-result.json`、`real-result.json`、`real-ui-verification.json`、`new-flow-view-verification.json`、`domain-validation/summary.json`、`validation/` 和 wheel 报告。浏览器验收脚本先后误把未选中的流程当页面正文、把“本次开发完成”写成“通过”；更正选择动作/文案后单独复核 UI，没有因此修改产品或再发模型请求。最终 UI 记录为 `real-ui-verification.json`。

## 当前边界

本次证明项目内开发、登记、固定算子测试、目录展示与只读计划链路；真实图片输入及质量定义仍需由业务需求给出。试用项目的生产运行权限保持关闭。

未精确定位的新 Lance 输出可能因 SDK 继续读取祖先 relocation 文件而在受限预览中失败；真实探针见 `lance-new-output-probe.json`。本批使用已配置精确输入/输出验证，没有开放祖先目录或更改 SDK。另一次额外的原生执行实验在读取 `/proc/self/cgroup` 时被开发验证边界拒绝，未作为运行通过证据；正常管道运行属于独立的运行权限和资源管理链路。这两项底层适配不在仓库授权的 Forge/工作台实现范围内，不声称已解决。

试用仍使用浏览器入口 `http://localhost:55972/`（转发至 devbox 59866），选择“Forge 开发试用”的原项目对话。无需创建任务或重新建立对话。实际运行提交、升级前后校验和恢复材料见共享评审目录的 `live-implementation-upgrade.json` 与部署核验记录。
