# Codex 开发与 Forge 操作台共享工作区：验收

日期：2026-11-03。对应[批准方案](forge-shared-workspace-panel-design-20261103.md)与[分阶段 Review](forge-workspace-sync-review-20261103.md)。

## 用户如何使用

一次性让 Codex 操作的 Forge 工作区与 `workspace view ROOT` 的 ROOT 指向同一绝对目录。查看服务长期运行；同一 SSH 入口可继续复用。当前 55971 保留原演示工作区，不能认为它会自动跟随任意聊天或仓库。

之后的一次实际开发迭代：

1. 在 Codex 提出要求：“将筛选阈值改成 0.90，检查并跑一版，保留原实验。”
2. Codex 保存 flows 下的配置，必要时修改 operators，调用现有检查、prepare、start。
3. 操作台自动显示新报告、新运行及真实状态；保存代码本身不会启动计算。
4. 到运行记录打开结果，看 Case、图片或按业务键比较。返回 Codex 描述下一轮修改，继续同样流程。

操作台不承担聊天，不要求选中 Case 发送上下文。普通浏览器可独立使用；不需要 Codex 插件或 Site Tools。Notebook 仍可作为可选项目代码，接线继续统一放在 flows。

## 验收矩阵

| 项目 | 验证方式 |
|---|---|
| 外部保存后更新项目说明 | 已打开普通浏览器 + 外部文件写入 |
| 新检查报告自动出现 | 外部真实 `forge flow inspect`，没有页面 POST |
| 报告因源码变化而 stale | 先建立当前工作区 checked 报告，再修改算子；验证明确 source_changed 原因 |
| Flow 草稿保留 | 源码变化后预算输入仍为用户值；报告仍更新依据 |
| 新运行、状态、结果同步 | CLI prepare/start → 页面同一 run_id → 固定版本实际 Case |
| 历史视图不抢跳 | 看 A 时创建 B，URL、Case 和版本保持 A |
| 有界闲置读取 | 无变化只检查元数据，不重复 sample/media；慢请求不积压 |
| 页面切换与 Case 竞态 | 延迟响应不得跳回旧页面或覆盖用户新选择 |
| 隐藏暂停与断线恢复 | 隐藏时无新检测，恢复后单次检查；断线保留内容，连接恢复后继续 |
| 手动/自动刷新合并 | 两种触发共用单条同步链，无 busy 错误 |
| 128 项运行列表 | 先校验所有身份，只读取当前页输出事件；SQL trace 无节点观察与写语句 |
| 通用日志依赖边界 | 非 Forge manifest 也可使用通用事件投影；不在原生日志解析 outputs |
| 运行语义回归 | 原生结果、A/B、继续加工、取消/部分提交、丢失监督进程与显式恢复 |
| 普通浏览器及离线导出 | 宿主 API 不参与；导出报告不启动同步 |
| 打包 | wheel/sdist 资产与最终源码一致，codex.js 已移除；包外导入与只读接口检查 |

66 个不同的相关测试项分批通过：完整相关回归批次 60 项；有界变化与日志投影 5 项；新增节点选择竞态 1 项。最终收敛后复测 10 项（与前述重叠），并在最终文件版本上再完成一次外部 CLI 两次实验到页面结果的全流程。没有把重复执行累计成新的测试项，也未宣称重跑全仓测试。

最终 wheel/sdist 已校验：页面资产与最终源码逐字节一致，已移除的 codex.js 未残留。解包到独立目录、在仓库外导入后，鉴权 changes 接口与离线导出均通过。

证据目录：`/tmp/forge-workspace-sync-z43yepy9`，包含分批测试日志、最终实验 JSON、源码范围核对、浏览器截图、包文件及实际入口检查。

## 保证边界

- 每次检测结束后再等待约 3 秒；实际延迟包含读取耗时，不是毫秒级实时或跨文件原子快照。
- 文件元数据仅提示可能变化。内容仍走现有摘要、固定表绑定和运行身份校验；手动刷新不依赖标记是否变化。
- 只同步已保存的工作区事实。编辑器未保存缓冲、聊天记录及其他仓库不在同步范围。
- 不自动 inspect、prepare、start、reconcile、bind-platform 或跟随 head；没有新增执行器、数据库、事件总线或 agent 控制服务。
- 查看平台服务自身的新代码仍须更新服务进程。同步工作区不能替代服务部署或绕过平台快照准入。
- 本阶段是本地受限工作区的开发与查看能力，没有新增正式 Review/Freeze 或生产放行功能。
